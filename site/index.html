A

Canonicalize

Text is normalized to Unicode NFC and consistent line endings, so equivalent text yields the same fingerprint.

B

Commit

Each document becomes a leaf in a SHA-256 Merkle tree. A compact path proves inclusion without the full batch.

C

Verify

The independent verifier recomputes the root. A trusted published root is needed to detect a forged or replaced proof.
